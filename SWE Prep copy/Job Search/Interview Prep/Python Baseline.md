Implement `repeated_device_ids(device_ids: list[str]) -> list[str]`.

Return each device ID that appears at least twice, exactly once, in the order of its **first appearance** in the input. IDs are case-sensitive. Do not modify the input.

Examples:

```python
repeated_device_ids([]) == []
repeated_device_ids(["A", "B", "C"]) == []
repeated_device_ids(["A", "B", "B", "A"]) == ["A", "B"]
repeated_device_ids(["X", "X", "X", "Y", "Y"]) == ["X", "Y"]
repeated_device_ids(["a", "A", "a"]) == ["a"]
```
