## Concepts to retain

- Function parameters and return values; `-> dict[str, int]` describes a dictionary with string keys and integer values.
- A string can be traversed directly with a `for` loop.
- Dictionary membership checks keys; `freq[char]` accesses the associated value.
- First occurrence initializes a count; subsequent occurrences increment it.
- `count += 1` works in Python; `count++` does not increment a value.
- Dictionary equality compares keys and values regardless of insertion order.
- Sets retain distinct values; frequency dictionaries also retain repetition counts.
- Analyze both work per iteration and iteration count. Space depends on stored distinct characters, not just string length.
