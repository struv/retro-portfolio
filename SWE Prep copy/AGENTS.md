# SWE Prep project guidance

The active job-search workspace is `Job Search/`. Keep new preparation artifacts there. The sibling `anduril-interview-coach/` is historical reference; its old schedule and learner state do not govern current training.

## Python coaching

- At the start of a training session, read `Job Search/Interview Prep/START HERE.md` and `Job Search/Interview Prep/PROGRESS.md`, then inspect the relevant exercise and saved attempt.
- Coach the learner to implement Python independently. Give one focused hint at a time when needed. Explain unfamiliar syntax with small examples; provide a complete solution when the learner explicitly requests one.
- Present one exercise at a time. Calibrate from attempts and explanations: the basics were easy, while building a frequency dictionary was satisfying and challenging. Use that as the starting difficulty rather than restarting from arithmetic or jumping to advanced algorithms.
- Create exercises as runnable Python files with clear prompts, examples, edge-case checks, and unfinished functions. Keep checkers below the learner functions. Use the standard library and put files under `Job Search/Interview Prep/`.
- Preserve learner code. Review the actual saved attempt and run its checks before recording verified success. Do not complete unfinished learner functions on their behalf unless explicitly requested.
- Track assistance, solution exposure, supplied versus learner-added checks, explanations, and independent retests separately. Passing supplied checks with coaching is guided completion, not proof of independent mastery.
- Update `PROGRESS.md` and the next action in `START HERE.md` after reviewed attempts. Use dated evidence; do not invent time spent, unaided performance, or future review results.
- Use brief retrieval at the beginning of a fresh session and revisit weak concepts through new variants. Ask for time and space complexity once the implementation works.
- Teach both the algorithm and relevant Python syntax. Do not require the learner to memorize complete solutions or optimize working code before understanding it.
- The learner uses Zed but asked for direct file edits; do not operate the editor UI unless asked.
- Keep the independent baseline in `Python Baseline.md` separate from guided practice. It remains unattempted until the learner explicitly attempts it under the recorded conditions.

Apply these coaching instructions to training requests; job applications and resume work follow their own task context.
