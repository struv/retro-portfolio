**Reporting window:** September 1–30, 2026, America/Los_Angeles (PDT, UTC−07:00). Queries use the half-open UTC interval `[2026-09-01 07:00:00, 2026-10-01 07:00:00)`. The main aggregate snapshot began October 13, 2026, at 22:10:31 UTC / 15:10:31 PDT. No production changes, sends, or raw-record exports were performed. Existing workspace edits were preserved.

## Calculation and evidence notes

- **Test filtering:** Patient and account text is examined only within the database for bounded words such as test, demo, dummy, sample, sandbox, training, e2e, Playwright, and Vitest. No dedicated production test flag was found on the relevant entities. At the September creation cutoff, the Kids & Teens filter excluded 355 possible test patient rows (`quality`). These are candidates, not confirmed tests: false positives and unmarked tests remain possible. Communication totals retain no message associated with a flagged patient in any inspected SMS source.
- **Patient deduplication:** Normalize case and whitespace in names, then group with birth date and organization. This follows the repository's existing demographic duplicate-detection approach. No names, dates of birth, demographics, hashes, or record values leave the SQL query. True person-level identity resolution remains unavailable.
- **Packet deduplication:** Use organization/appointment/primary-group tuples rather than adding responses, document-status rows, PDF rows, and resends. Multiple document groups attached to a session remain part of its bundle. This heuristic does not fully resolve duplicated appointments or repeated packet versions.
- **Staff history:** Monthly activity uses dated events rather than `lastSignedIn`, which is overwritten. No audit archive batches overlapping September were found in the inspected archive metadata (`inventory.archives`). That does not prove there have never been deleted or unrecorded events.
- **SMS reconciliation:** A provider reference is counted once across overlapping logs; failure takes precedence over delivered/read, then sent. Queue send time has priority over earlier link-log timestamps. Placeholder creation, queue cancellation, and repeated mirror rows do not count as transmissions. New provider references represent separate actual sends even if message text is identical; content is not read or compared by this audit.
- **Historical limits:** These are October 13 queries over retained production records, not an immutable September-close export. Later patient corrections, account deletions, packet reopening, or log retention can change a rerun. One retained session has a completion timestamp with a non-completed current status (`packets`); completed-packet metrics require both completed status and the qualifying timestamp. No completed-status row lacked a completion timestamp in the inspected data.
- **Failed supplementary query:** An additional cross-source diagnostic exceeded the bounded statement timeout and returned no result. It is excluded from the reported evidence and reproduction file. The reported usage, packet, transmission, email-log, and queue-timing queries completed successfully.

Source code was inspected from the September release revision rather than treating the dirty local checkout as production truth.
