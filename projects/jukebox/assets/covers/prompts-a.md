# Generated cover artwork — set A

Created with the built-in `image_gen` tool, one separate generation per cover, with `transparent_background: false`; no reference images. These are original cover illustrations for the user's songs, not replicas of commercial album artwork. Each PNG was copied unmodified from the tool output into this project. No Python image editing, third-party stock assets, or CLI/API fallback was used.

All three generated images were visually inspected: square full-bleed art, coherent navy/cyan/magenta or lavender palette, recognizable central imagery, and no text, letters, logos, watermarks, packaging, or disc mockups. The square artwork is intended for both thumbnails and circular CD texture mapping; the CD center hole is added by the existing 3D mesh.
